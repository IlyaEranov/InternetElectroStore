Регистрация пользователя

При регистрации пользователя должна проходить валидация запроса на стороне клиента перед отправкой данных на сервер

После того как данные поступили на сервер должна проходить проверка валидации уже на сервера (с точки зрения перестраховки)

Далее данные из объекта должны представлять модель пользователя

Начальная структура пользователя:
email
name
password

Далее должна проходить проверка на существующий email с обработкой ошибок

Далее происходит создание двух токенов авторизации для пользователя (refresh и access)
Для храненения паролей в базе данных будет использоваться хэширование
Далее идет запрос к базе данных на создание нового пользователя 
После создания пользователя ему на почту должно отправляться сообщение о подтверждении почты
